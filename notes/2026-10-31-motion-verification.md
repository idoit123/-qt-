# 运动检测验证记录

2026-10-31，在此前 JPEG/TCP 灰度回传功能上升级为彩色运动检测。

## 实现

- Linux OpenCV MOG2，检测输入按比例缩小到不超过 320×240，灰度平滑后背景减除，关闭阴影检测。
- 前 20 帧学习背景、不输出运动框；之后形态学开闭运算去噪，过滤小轮廓，按面积最多保留 16 个框。
- 输出保持彩色，绿色运动框映射回原图坐标；区域数不代表人数，不识别物体类别。
- 每个 TCP 连接独立持有背景模型，仅处理线程操作模型；断连后随最后引用释放，无永久增长的模型表。
- PDU 后 32 字节：请求 `reset`，响应 `warmup:N/20`、`idle:0` 或 `motion:N`，不改变 JPEG 正文布局。
- Qt 新增状态提示、“重置背景”和不使用摄像头的“运动演示”；源切换时重置，分辨率变化时服务端自动重置。
- 保留单帧在途、16 个待办任务、512 KiB / 1280×720 限制、登录认证、5 秒超时和 Reactor 线程回传。

## 已通过的验证

环境：Windows Qt 5.14.2 / MinGW 7.3；Ubuntu WSL2 / GCC 11.4 / OpenCV 4.5.4，Release。

- 客户端、服务端编译成功。
- CTest 4/4：核心、视频运动集成、文件业务、聊天业务。
- 视频集成：两个不同场景并行回传、20 帧学习、静止场景不触发、单像素噪声不触发；
  移动物体触发且实际 JPEG 中存在绿色框；运动消失后回到 idle；另一连接不受影响；
  手动重置、重新学习后的静止场景、分辨率切换、断连后新连接重新学习。
- 保留 TCP 分片、身份拒绝、非法 JPEG、尺寸/长度上限、失败恢复和带任务断连测试。
- Windows 原生 MonitorTest：4 passed（含初始化/清理），验证注册、彩色回显、学习→静止→运动、重置背景、停止采集和断开。
- Windows Qt 到 WSL 独立测试端口 18890：`QT_MOTION_SMOKE_PASS frames=30`。
- 人工检查测试生成的 `build-video-ui-test/monitor-motion-ui.png`：右侧移动方块被绿色框包围，静止背景区域未标框，状态显示一个运动区域。
